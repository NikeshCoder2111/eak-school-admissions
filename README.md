# EAK International School – Admissions Landing Page (2027–28)

A responsive, frontend-only admissions landing page built for the EAK Pustak hiring assignment (Project 02).

## Tech used
- HTML5 (semantic tags, `<dialog>` for the modal)
- CSS3 (custom properties, Grid, Flexbox, media queries). No libraries or frameworks.
- Vanilla JavaScript (mobile menu, accordion, modal, counters)
- Images: placeholder photos from picsum.photos (externally hosted, requires internet)

## How to run
1. Download or clone this folder.
2. Open `index.html` in any modern browser. No build step or server needed.

## Features
- All 12 required sections with dummy content
- Sticky navbar with smooth scrolling and mobile hamburger menu
- Apply Now / Book a Campus Visit / Talk to Admissions open a frontend-only enquiry modal with a confirmation message
- FAQ accordion with keyboard and ARIA support
- Responsive for mobile, tablet and desktop
- Accessibility: skip link, labels, focus styles, alt text, reduced-motion support

## Note
All names, dates, fees and statistics are fictional. No backend or real form submission.
